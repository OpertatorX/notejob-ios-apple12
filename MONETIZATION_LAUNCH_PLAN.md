# OX Invoice — Monetization launch plan

## Launch offer
- Free download.
- First **3 created documents** free.
- Pro 6 months: target €9.99.
- Pro yearly: target €16.99.
- No ads.

## Funnel to measure
1. App Store product page → install.
2. Install → business setup.
3. Business setup → first saved document.
4. First document → successful PDF share.
5. Third document → paywall impression.
6. Paywall → plan selected.
7. Purchase sheet → verified entitlement.
8. Renewal / cancellation over time.

The production app intentionally contains no third-party analytics. Use App Store Connect subscription metrics and sales data for the first release rather than adding a tracking SDK before launch.

## Pricing rules
- Keep the launch prices stable long enough to obtain a meaningful cohort.
- Do not discount before measuring baseline conversion.
- If conversion is strong, test price increases before adding more complexity.
- Annual remains the value anchor.
- If users ask for a one-time purchase in reviews, evaluate a lifetime unlock later; do not launch every pricing model at once.

## Product rules for revenue
- Preserve the 3-document free trial: it proves PDF quality before purchase.
- Never interrupt document editing with ads.
- Paywall only when value is understood.
- Keep PDF quality as the main retention/word-of-mouth asset.
- Prioritize requested recurring-value improvements for subscription defensibility: recurring invoices, payment reminders, backup/sync/export improvements, richer templates and business reports.
