# NoteJob V2.3 — France Complete

Cette version renforce le moteur de recherche afin qu’une entreprise ou un établissement public présent dans les sources officielles françaises soit retrouvable même lorsque l’enseigne utilisée par l’utilisateur diffère de la raison sociale.

Ordre de résolution : recherche officielle locale → variantes/alias → POI + recherche officielle autour du lieu → recherche nationale de secours → SIREN/SIRET direct.

Limite normale : une entité non diffusée ou dont les données sont volontairement masquées dans les registres publics ne peut pas être exposée par NoteJob.
