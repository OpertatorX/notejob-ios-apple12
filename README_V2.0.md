# NoteJob V2.0 Refined

Version de finition de l’interface iOS NoteJob.

Le moteur entreprise + ville, l’Employer Resolver, Supabase, les notes anonymes, les favoris, les signalements et AdMob/UMP restent présents. La V2.0 se concentre sur la réduction du bruit visuel : accueil photo-first, recherche plus intégrée et résultats directement dans la home.

## Preview

Double-cliquer `OPEN_PREVIEW.bat` dans le projet ou utiliser le ZIP `NoteJob-V2.0-LOCAL-PREVIEW`.

## Parcours principal

Accueil → Entreprise + Ville → résultats inline → fiche entreprise → Noter cette entreprise.
