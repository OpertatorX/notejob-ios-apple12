# Sources média NoteJob V1.5

Ordre de priorité :

1. média manuel NoteJob lié au SIRET ;
2. média manuel NoteJob lié au SIREN ;
3. site officiel retrouvé via le POI OpenStreetMap exact ou Wikidata ;
4. image OpenGraph / Twitter Card / Schema.org `image` du site officiel ;
5. logo Schema.org / favicon du site officiel ;
6. média Wikidata / Wikimedia Commons lié à l'entité ;
7. fallback graphique NoteJob.

La V1.5 n'utilise plus Panoramax comme hero d'entreprise et n'utilise pas Google Places.
