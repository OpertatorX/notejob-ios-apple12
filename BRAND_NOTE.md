# Brand note

The public release name is **OX Invoice**.

The earlier working name, **QuoteFlow**, was intentionally removed from the final source because an existing iOS app already uses the QuoteFlow name for a closely overlapping estimate/invoice product. Keeping that name would create unnecessary App Store and branding risk.

All public-facing app metadata, bundle ID, subscription product IDs, legal pages, review notes, support URLs, splash/loading branding and the iOS icon now use OX Invoice.
